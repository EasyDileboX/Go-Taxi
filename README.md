# Go Taxi

Go Taxi (Go-Taxi) — Community-driven taxi & shuttle booking app for South Africa.

This repository contains a starter Expo React Native project (mobile) and a small admin stub. The starter implements:

- Expo app scaffold (role selection: passenger / driver)
- Firebase placeholders for Auth & Firestore
- Map placeholder and notes to configure Google Maps (South Africa)
- Passenger booking form skeleton (supports daily shuttles, parcel delivery, charter)
- Driver view skeleton with location update hooks (isMoving detection to be implemented)
- Firestore security rules snippet enforcing max 12 passengers per ride
- README with setup steps and environment variables

Note: This is a starter scaffold. You must provide your Firebase config and Google Maps API key; no secrets are committed here.
